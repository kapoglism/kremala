# Κρεμάλα

Το κλασικό παιχνίδι της κρεμάλας στα ελληνικά, για το terminal, γραμμένο σε Python. Το πρόγραμμα διαλέγει κρυφά μια λέξη και εσύ τη μαντεύεις γράμμα-γράμμα, πριν τελειώσουν οι προσπάθειές σου.

## Πώς παίζεται

```
Η λέξη έχει 6 γράμματα:
_ _ _ _ _ _
Δώσε γράμμα α
Υπάρχει το γράμμα : α
_ α _ α _ _
```

- Έχεις **6 προσπάθειες**. Χάνεις μία μόνο όταν το γράμμα δεν υπάρχει στη λέξη.
- Κάθε γράμμα που βρίσκεις εμφανίζεται σε όλες τις θέσεις του.
- Σε κάθε γύρο βλέπεις ποια λάθος γράμματα έχεις ήδη δώσει.
- Στο τέλος μαθαίνεις αν κέρδισες και, αν έχασες, ποια ήταν η λέξη.
- Μπορείς να ξαναπαίξεις με νέα λέξη, και το πρόγραμμα κρατάει σκορ με τις νίκες και τις ήττες σου.

## Τι αντέχει η είσοδος

- Δέχεται γράμματα με ή χωρίς τόνο, μικρά ή κεφαλαία.
- Το `σ` και το `ς` μετράνε ως το ίδιο γράμμα.
- Απορρίπτει, χωρίς να χάνεις προσπάθεια, πολλά γράμματα μαζί, αριθμούς, σύμβολα, κενή είσοδο και γράμματα που έχεις ήδη δώσει.

## Πώς το τρέχεις

Χρειάζεσαι μόνο Python 3. Δεν χρειάζεται εγκατάσταση πακέτων.

```bash
py kremala.py
```

Σε Linux ή macOS:

```bash
python3 kremala.py
```
